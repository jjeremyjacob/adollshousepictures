TIME OFFSET WINDOW

A minimal single-effect video page. Move the cursor over the video to reveal a circular window showing the same footage eight seconds earlier. The window radius is fixed at 180px, and there is no outline or visible control UI.

The main video is scrubbed by scrolling the page. Place your source video at:

  video/1.mp4

Open index.html through a local web server for best browser compatibility. For example, from this folder:

  python3 -m http.server 8000

Then visit http://localhost:8000.
